## 📖 Detailed Feature Guide

### Movement & Exploration

The main campaign is controlled from a strategic map of England rather than through continuous free-roaming. Select territories, castles, and campaign actions from the map. In Retro and Classic modes, most major actions consume campaign time, so activate turn-related options before selecting an action when necessary.

### Tools & Inventory

The game has no conventional character inventory. Its main tracked resources are gold, soldiers, knights, catapults, castles, fame, and campaign progress. Kingdom Mode additionally uses hearts, Precious Dice, and unlockable abilities. Use the trainer only after the relevant value is visible in the current mode.

### World & Environment

Expand across England by recruiting forces, transferring troops, capturing provinces, defending holdings, and attacking fortified castles. Retro Mode recreates the original campaign, Classic Mode modernizes its presentation and systems, and Kingdom Mode uses procedurally generated maps, dice mechanics, unlockable abilities, and multiple difficulty levels.

### Combat & Weapons

Field campaigns and castle assaults depend on army composition and siege preparation. Catapults weaken castle defenses before the assault, while soldiers and knights form the main fighting force. Raids and rescues use side-scrolling sword fights, and tournaments use jousting encounters. Activate combat options before entering the relevant sequence.
